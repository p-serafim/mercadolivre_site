Como publicar no GitHub Pages

  1. Crie um repositório público no GitHub (ex: ml-price-tracker).
  2. Envie este arquivo como index.html no repositório.
  3. Vá em Settings > Pages no seu repositório.
  4. Em Branch, selecione main e salve. Seu site estará online!

Transparência da API

Este monitor consome diretamente os endpoints públicos oficiais da API REST do Mercado Livre Brasil (api.mercadolibre.com). Os dados de preços, parcelamento, reputação de vendedores e histórico do monitor são sincronizados em tempo real no seu próprio navegador.

Armazenamento Seguro

Todos os seus dados de Watchlist, alertas de preço alvo e tags de afiliados são mantidos localmente no seu localStorage do navegador. Nenhum dado de navegação é enviado para servidores externos.
